# Configuracion del icono del servidor

Es posible configurar el icono que aparece en la lista de servidor para conexion. El icono debe cumplir las siguientes caracteristicas:

* Formato PNG.
* Tamaño 64x64.
* El archivo se debe llamar **server-icon**.

El archivo de icono se debe dejar en la carpeta principal del servidor y este lo tomara automaticamente.
