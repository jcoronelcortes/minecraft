# Creacion de armaduras propias

Se debe instalar Blockbench para editar la amarmadura:

https://www.blockbench.net/

# Paso 1 - Crear y pintar la armadura
Una vez instalado el programa, se debe instalar el plugin **CEM Template Loader**.

Luego se debe cargar el CEM Template loader desde la parte izqueirda del programa, ir a la categoria **Unsupported** y seleccionar la categoria **Armor**.

La opcion **Armor** muestra dos porjectos. El primero es la armadura principal y el segudno los pantalones.

Una vez cargado el proyecto se debe seleccionar la opcion **'Archivo -> Convertir proyecto'** y convertirlo a un proyecto **Java**.

Finalmente se creara un nuevo tab con ekl proyecto (cerrar el tab inicial) y se debe guardar el proyecto con un nombre.


# Paso 2 - crear la carpeta de recurso en el servidor

Una vez creada la armadura, se debe ingresar a la opcion 'Opciones -> Paquetes de recursos', hacer click en 'Abrir carpeta' y una nueva carpeta de recursos.
