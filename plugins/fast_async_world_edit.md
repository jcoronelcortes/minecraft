# Fast Async World Edit

FastAsyncWorldEdit (FAWE) es una bifurcación optimizada del plugin de edición de mundos WorldEdit para Minecraft, diseñada para ofrecer un rendimiento y manejo de memoria superiores mediante operaciones asíncronas. Proporciona las mismas potentes herramientas que WorldEdit para la manipulación de grandes áreas de bloques, pero con una eficiencia significativamente mayor, lo que resulta en una experiencia de edición más fluida y con menos lag, especialmente útil para construcciones complejas.

https://www.spigotmc.org/resources/fastasyncworldedit.13932/

## Como cargar un Chematic

Para cargar un nuevo mundo que este en formato chematic dentro del servidor se debe realizar los siguientes pasos:

* Dejar el o los nuevos mundos en la carpeta **'chematics'** dentro del servidor.
* Ejecutar el comando **'/chematic list'** y mostrara los nuevos mundos que se pueden cargar.
* Ejecutar el comando (o seleccionar desde el menu del list) **'/chematic load [archivo_schem]'** para cargar el chematic.
* Ejecutar el comando **/paste** para pegarlo.
