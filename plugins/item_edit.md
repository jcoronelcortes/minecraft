# Item Edit

ItemEdit es un plugin para servidores de Minecraft que permite a los administradores y usuarios modificar y crear ítems personalizados con encantamientos, atributos, descripciones y otros detalles. Funciona mediante comandos para alterar un ítem en la mano del jugador, como cambiar su nombre, agregarle lore (texto descriptivo), ocultar información, o añadir efectos de poción y encantamientos especiales que no son posibles en el juego normal. Es una herramienta popular para crear armas y objetos poderosos o únicos para servidores de rol o supervivencia.
