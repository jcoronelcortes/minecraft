# Via Version

Es un plugin de servidor para Minecraft que permite a los jugadores conectarse a un servidor usando una versión de Minecraft diferente a la que el servidor está ejecutando, solucionando problemas de compatibilidad entre versiones. Este plugin es fundamental y se puede complementar con ViaBackwards para permitir que versiones antiguas se conecten a servidores nuevos, y con ViaRewind para que versiones aún más antiguas (como 1.7 y 1.8) puedan unirse a servidores modernos.
