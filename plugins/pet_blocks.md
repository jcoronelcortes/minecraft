# Pet Blocks

El plugin PetBlocks para Minecraft permite a los jugadores tener mascotas hechas de bloques y cabezas de jugadores o bloques personalizados, las cuales siguen al jugador, se pueden personalizar con skins diferentes y nombres, e incluso se les pueden añadir efectos de partículas, sonido y darles efectos de poción para beneficiar al jugador. Es un plugin de decoración y utilidad que se gestiona mediante comandos o un menú gráfico y funciona en servidores de Spigot y Sponge

https://www.spigotmc.org/resources/petblocks-gui-programmable-geysermc-custom-models-folia-1-21-8.12056/
