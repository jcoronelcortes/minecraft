# Via Backwards

Permite que jugadores con versiones más antiguas del cliente (a partir de la versión 1.9) se conecten a servidores que ejecutan versiones más recientes del juego. Para que funcione, es indispensable tener instalado también el plugin ViaVersion, que es el complemento principal que permite la compatibilidad de versiones en el servidor.

https://www.spigotmc.org/resources/viabackwards.27448/
