# Skins Restorer

Es un plugin para servidores de Minecraft que permite a los jugadores de servidores "no premium" (o "crackeados") usar y visualizar skins personalizadas, solucionando el problema de que estos servidores no se conectan con los servidores de Mojang para obtener la apariencia del jugador. Se instala en el servidor y permite a los jugadores cambiar su skin mediante comandos como /skin set <nombre de usuario> o /skin set <URL de la skin>, e incluso cambiar las skins de otros jugadores.

https://www.spigotmc.org/resources/skinsrestorer.2124/

>**NOTA:** Desde el 07-nov-2026 el servidor esta en modo online, por lo que cada jugador ya tiene su skin de Microsoft. El plugin se mantiene para poder cambiar de skin (por ejemplo, a personajes de [Hora de Aventuras](../servidor/hora_de_aventuras.md)).

## Comandos

* **/skins:** Menu con skins sugeridas.
* **/skin set \[nombre_jugador]:** Copia la skin de otra cuenta.
* **/skin url \[enlace_imagen_png]:** Usa una skin desde una imagen.
* **/skin clear:** Vuelve a la skin propia.

Hay que esperar 30 segundos entre cambios. Los comandos **/skin** y **/skins** deben estar en la lista de [Easy Command Blocker](easy_command_bloquer.md).
