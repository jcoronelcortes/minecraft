# Placeholder API

PlaceholderAPI es un plugin para servidores de Minecraft que funciona como un sistema de "etiquetas" o variables (placeholders) que otros plugins pueden utilizar para mostrar información útil, como el nivel de un jugador, su ping, dinero, o datos del propio servidor, en lugares como el chat, las scoreboards o los tabuladores. Permite a los servidores tener una información muy detallada y personalizada, ya que muchas de estas variables se obtienen de otros plugins instalados o a través de "expansiones" propias del PlaceholderAPI.

https://www.spigotmc.org/resources/placeholderapi.6245/

Cada vez que ser realiza un cambio (descarga de variables por ejemplo), se debe ejecutar el siguiente cambio para que el servidor carge los cambios:

* **/papi reload**

## Descarga de las variables (placeholders) de otros plugins

Para poder utilizar las variables de otros plugins en Luck Perms, primero se debe descargar las variables ejecutando el comando:

* **/papi ecloud download \[nombre_plugin]**
